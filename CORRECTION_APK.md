# Correction APK autonome

Cette version retire `expo-dev-client` et compile `assembleRelease`.
L’APK générée ouvre directement Visomoot et ne demande pas de serveur Expo.

Dans GitHub Actions : **Build Visomoot APK** → **Run workflow**.
À la fin, télécharger l’artifact **Visomoot-APK**, puis installer `app-release.apk`.
